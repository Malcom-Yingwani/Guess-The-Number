# Guess The Number

Guess The Number is a simple JavaScript game where the player tries to guess a randomly generated number within a limited number of attempts.

This project was built to practice basic programming concepts such as loops, conditionals, and user input handling.

## Features
- Random number generation
- User input validation
- Feedback on guesses
- Limited number of attempts

## Technologies
- JavaScript, HTML, CSS

## Purpose
This project exists as a beginner-friendly exercise to reinforce core programming logic and problem-solving skills.
